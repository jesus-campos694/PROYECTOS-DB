Laboratorio práctico de administración de SQL Server sobre Ubuntu Server, enfocado en tareas de *DBA Jr*.

Objetivo: Documentar el proceso de instalación, configuración y administración de SQL Server en Linux, demostrando habilidades prácticas para roles de:

- Diseño de bases de datos
- Administración de bases de datos
- Creación de usuarios y administración de permisos
- Consultas T-SQL
- Índices y optimización
- Respaldos y restauración
- Monitoreo básico
